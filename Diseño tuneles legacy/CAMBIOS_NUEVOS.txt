🐛 SI ALGO FALLA
═════════════════════════════════════════════════════════════════════════════

1. Error al instalar ReportLab:
   → Abre terminal como administrador
   → Ejecuta: pip install reportlab --break-system-packages

2. El PDF no se descarga:
   → Revisa consola del navegador (F12)
   → Revisa ventana de TEST_APP.bat para errores

3. Excel vacío:
   → Verifica que llenaste al menos nombre y cliente
   → Revisa que los datos se envían correctamente
