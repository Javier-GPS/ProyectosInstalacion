BACKEND (Flask)
───────────────
✓ test_app.py
  • Servidor Flask en puerto 5000
  • Endpoints:
    - GET  /                          (frontend HTML)
    - POST /api/calcular              (cálculos fotométricos)
    - GET  /api/luminarias            (lista de LDTs)
    - POST /api/submit-form           (genera Excel + PDF)
    - GET  /api/debug/ldts            (diagnóstico)
  • Precarga de LDTs en caché al inicio
  • Generación de Excel con openpyxl
  • Generación de PDF con reportlab

LIBRERÍAS FOTOMÉTRICAS
──────────────────────
✓ photometry.py
  • Clase: CalculoFotometrico
  • Métodos:
    - calcular_iluminancia()          → Em (lux)
    - calcular_luminancia()           → L (cd/m²)
    - calcular_uniformidad()          → Uo, Ul
    - calcular_deslumbramiento()      → TI, SR
    - calcular_consumo_energetico()   → Potencia, consumo, cost, CO2
  • Norma: EN 13201:2015

✓ visualization.py
  • Clase: VisualizacionFotometrica
  • Métodos:
    - generar_malla_isocurvas()       → Malla 50x100 con Gaussiana
    - crear_grafico_iluminancia()     → Contour plot con 6 isolíneas
    - crear_grafico_luminancia()      → Same for luminancia
    - grafico_a_base64()              → Para HTML
    - grafico_a_bytes()               → Para PDF
  • 6 isolíneas con relleno de color
  • Escala gradiente: azul → verde → amarillo → rojo

LECTURA DE LDTs
───────────────
✓ ldt_reader.py
  • Clase: LDTReader
  • Métodos:
    - extraer_zip_ldts()              → Lee archivos de ZIP
    - parsear_ldt()                   → Extrae metadatos
  • Soporta formatos:
    - .ldt (estándar)
    - .ies (IESNA)
    - Archivos sin extensión
  • Extrae: nombre, fabricante, flujo, ángulos, intensidades

FRONTEND (HTML/JavaScript)
──────────────────────────
✓ templates/index.html
  • Layout: 3 columnas CSS Grid
  • 6 secciones de formulario:
    1. Datos del Proyecto (8 campos)
    2. Geometría (14+ campos)
       - Calzada (ancho, largo, altura, pendiente)
       - Acera (ancho, largo, altura, pendiente)
    3. Luminarias (dropdown + tarjetas dinámicas)
       - Selector: "-- Seleccionar luminaria --"
       - Auto-relleno desde LDT: modelo, óptica, lúmenes
       - Campos: Modelo, Óptica, Potencia, Lúmenes, Objetivo
    4. Energía y Sostenibilidad (5 campos)
    5. Entregables (3 checkboxes)
    6. Resultados (oculto hasta calcular)
  • Botones:
    - CALCULAR (azul): ejecuta /api/calcular
    - GENERAR INFORMES (rojo): ejecuta /api/submit-form
  • Funciones:
    - cargarLuminarias()              → GET /api/luminarias
    - seleccionarLuminaria()          → Auto-rellena tarjeta
    - calcularFotometria()            → POST /api/calcular
    - mostrarResultados()             → Display Em, Uo, Ul, TI, SR, etc.
    - generarInformes()               → POST /api/submit-form

⚙️ CÓMO FUNCIONA EL FLUJO
═════════════════════════════════════════════════════════════════════════════

1. USUARIO ABRE http://localhost:5000
   ↓
   test_app.py carga index.html
   JavaScript ejecuta cargarLuminarias()
   ↓
   GET /api/luminarias
   ↓
   ldt_reader.py lee assets/LDTs_luminarias.zip
   Extrae 27 luminarias
   ↓
   Retorna JSON con lista de opciones
   ↓
   Dropdown en Sección 3 se llena con 27 opciones

2. USUARIO SELECCIONA UNA LUMINARIA
   ↓
   seleccionarLuminaria() se ejecuta
   ↓
   Busca datos de la luminaria en la lista
   ↓
   Crea tarjeta azul con campos pre-rellenados:
   - Modelo: nombre del LDT
   - Óptica: fabricante
   - Lúmenes: flujo extraído del LDT
   ↓
   Usuario puede editar si es necesario

3. USUARIO LLENA FORMULARIO Y PRESIONA "CALCULAR"
   ↓
   calcularFotometria() recopila datos
   ↓
   POST /api/calcular con datos JSON
   ↓
   photometry.py ejecuta CalculoFotometrico
   visualization.py genera 2 gráficos isocurvas
   ↓
   Retorna resultados + imágenes en base64
   ↓
   mostrarResultados() muestra:
   - Sección 6 "RESULTADOS"
   - Valores calculados (Em, Uo, Ul, TI, SR, etc.)
   - Indicadores de cumplimiento normativo
   - Dos imágenes de isocurvas

4. USUARIO PRESIONA "GENERAR INFORMES"
   ↓
   generarInformes() recopila datos + resultados
   ↓
   POST /api/submit-form
   ↓
   crear_excel_completo() genera XLSX con:
   - Hoja "Proyecto": datos del proyecto
   - Hoja "Geometría": datos de geometría
   - Hoja "Luminarias": tabla de luminarias
   - Hoja "Energía": datos de consumo
   - Hoja "Resultados": cálculos fotométricos
   ↓
   crear_pdf() genera PDF con:
   - Tablas de datos
   - Gráficos de isocurvas (iluminancia + luminancia)
   ↓
   Descarga automática de XLSX y PDF
