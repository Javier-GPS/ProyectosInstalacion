NOTAS
═══════════════════════════════════════════════════════════════════════════

1. Los directorios uploads/ y downloads/ se crean automáticamente
   cuando ejecutas la aplicación.

2. Los archivos en uploads/ se eliminan automáticamente después del
   procesamiento (seguridad y limpieza).

3. Los archivos en downloads/ se mantienen para que el usuario pueda
   descargarlos. Considera limpiar periódicamente.

4. Todos los imports están en la parte superior de cada archivo.
   Las dependencias están listadas en requirements.txt

5. El archivo index.html contiene TODO el frontend: HTML + CSS + JavaScript
   en un solo archivo para facilitar deployment.

6. Las configuraciones están centralizadas en config.py para fácil
   modificación sin tocar el código principal.

7. Los módulos en la carpeta modules/ son reutilizables en otros
   proyectos Flask si es necesario.
