🔍 PARSEO DE ARCHIVO LDT
═════════════════════════════════════════════════════════════════════════════

Formato LDT (texto ASCII):
Línea 1: Nombre luminaria
Línea 2: Fabricante
Línea 3: Tipo
Línea 4-7: Datos numéricos (incluye flujo luminoso)
Línea 8: Ángulos C (azimuth)
Línea 9: Ángulos G (inclinación)
Línea 10+: Valores de intensidad luminosa

El lector extrae:
   • Nombre (línea 1)
   • Fabricante (línea 2)
   • Tipo (línea 3)
   • Flujo luminoso (línea 4, valor 100-1000000)
   • Max intensidad (del resto de líneas)


💾 CACHÉ EN MEMORIA
═════════════════════════════════════════════════════════════════════════════

Al iniciar TEST_APP.bat:
   • Se lee ZIP una sola vez
   • Se guardan en variable LDTS_CACHE
   • API devuelve desde caché (muy rápido)

Ventajas:
   ✓ No re-leer ZIP en cada petición
   ✓ Respuesta instantánea
   ✓ Bajo overhead de memoria


⚠️ ERRORES COMUNES
═════════════════════════════════════════════════════════════════════════════

"No hay luminarias disponibles":
   → ZIP no encontrado en assets/
   → ZIP vacío (sin .ldt)
   → ZIP corrupto

Solución:
   1. Verifica: assets/LDTs_luminarias.zip existe
   2. Descomprime en otro programa, verifica .ldt
   3. Reinicia TEST_APP.bat

Dropdown no carga:
   → Error en /api/luminarias (F12 Network tab)
   → JavaScript error en consola
   → Revisa logs de TEST_APP.bat

Si archivo LDT no se lee:
   → Encoding: el lector intenta UTF-8 y Latin-1
   → Formato: verifica que sea formato LDT válido
   → Check: primeras 10 líneas tienen datos

"TypeError: luminaria is undefined":
   → Bug en seleccionarLuminaria()
   → Revisa consola browser (F12)
