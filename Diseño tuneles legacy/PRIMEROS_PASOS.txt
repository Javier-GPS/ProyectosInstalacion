PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════════

P: "Python no reconocido"
R: Python no está instalado o no está en PATH
   → Descarga desde https://www.python.org/downloads/
   → Marca "Add Python to PATH"
   → Reinicia tu PC

P: INSTALAR.bat falla
R: Hay un problema con setuptools
   → Lee SOLUCIONAR_PROBLEMAS.md sección "pip build fails"

P: CORRER.bat no abre la aplicación
R: La terminal se cierra muy rápido
   → Abre CMD/PowerShell manualmente
   → Ve a la carpeta del proyecto
   → Ejecuta: python app.py
   → Abre navegador: http://localhost:5000

P: "Port 5000 already in use"
R: Otro programa usa el puerto 5000
   → Edita app.py última línea
   → Cambia port=5000 a port=5001
   → Abre navegador: http://localhost:5001
