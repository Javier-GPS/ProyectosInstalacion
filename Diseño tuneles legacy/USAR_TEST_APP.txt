¿QUÉ ES TEST_APP?
═════════════════════════════════════════════════════════════════════════════

Una versión SIMPLIFICADA de la aplicación que:
✓ No depende de módulos complicados (excel_handler, validators)
✓ Genera un Excel básico pero funcional
✓ Es mucho más fácil de debuggear
✓ Te ayuda a identificar exactamente dónde está el problema

SI FUNCIONA TEST_APP
═════════════════════════════════════════════════════════════════════════════

Entonces el problema está en:
   ❌ modules/excel_handler.py (complicado)
   ❌ modules/validators.py (estricto)
   ❌ app.py (app original)

Solución: Usaremos la versión de app.py simplificada basada en test_app.py


SI NO FUNCIONA TEST_APP
═════════════════════════════════════════════════════════════════════════════

1. Mira la consola del navegador (F12):
   ¿Qué error dice?

2. Mira la ventana de terminal (donde corre TEST_APP.bat):
   ¿Qué dice en rojo o en ERROR?

3. Abre en navegador:
   http://localhost:5000/api/debug/files

   Verifica:
   ✓ "download_folder_exists": true
   ✓ Los archivos generados aparecen en "files_in_downloads"


INFORMACIÓN TÉCNICA
═════════════════════════════════════════════════════════════════════════════

Test_App hace exactamente esto:

1. Recibe los datos del formulario como JSON
2. Valida que tengas nombre_proyecto y cliente_final
3. Crea un Workbook con openpyxl
4. Agrega los datos como simple tabla
5. Guarda en carpeta /downloads
6. Devuelve URL para descargar

Sin dependencias complicadas. Si esto no funciona, hay un problema
fundamental con Python o Flask.


COMANDO ALTERNATIVO (sin .bat)
═════════════════════════════════════════════════════════════════════════════

Si TEST_APP.bat no abre, prueba manualmente en PowerShell:

1. Abre PowerShell en la carpeta del proyecto
2. Ejecuta:
   .\venv\Scripts\activate.bat
   python test_app.py

3. Si ves "Running on http://127.0.0.1:5000", está funcionando
