🔧 PASOS PARA DIAGNOSTICAR
═════════════════════════════════════════════════════════════════════════════

PASO 1: Verificar que LDT Reader funciona
─────────────────────────────────────────

   Ejecuta: TEST_LDTS.bat

   Deberías ver:
   ✓ Ruta: assets/LDTs_luminarias.zip
   ✓ Existe: True
   ✓ Total: X luminarias
   ✓ Primeras 5 luminarias listadas

   Si ves ERROR:
   → ZIP no encontrado
   → ZIP vacío (sin .ldt)
   → Formato .ldt incorrecto


PASO 2: Verificar endpoint /api/luminarias
───────────────────────────────────────────

   1. Asegúrate que TEST_APP.bat está corriendo
   2. Abre navegador: http://localhost:5000/api/debug/ldts

   Deberías ver JSON con:
   {
     "status": "ok",
     "ldts_zip_path": "...",
     "ldts_zip_exists": true,
     "ldts_cache_loaded": true,
     "ldts_cache": {
       "success": true,
       "total": X,
       "luminarias": [...]
     }
   }

   Si ldts_zip_exists = false:
   → ZIP no existe en assets/

   Si ldts_cache_loaded = false:
   → No se cargó al iniciar

   Si success = false en ldts_cache:
   → Error al parsear LDTs


PASO 3: Verificar JavaScript en navegador
──────────────────────────────────────────

   1. Abre http://localhost:5000
   2. Presiona F12 (consola del navegador)
   3. Busca errores rojos

   Deberías ver:
   ✓ "Luminarias cargadas: {success: true, ...}"
   ✓ "✓ X luminarias cargadas"

   Si ves error:
   → Haz clic derecho → "Inspeccionar elemento"
   → Busca el select#ldt-selector
   → ¿Está en HTML?


PASO 4: Verificar HTML
──────────────────────

   1. Abre http://localhost:5000
   2. Presiona F12 → Elements/Inspector
   3. Busca: Sección 3 Luminarias
   4. ¿Existe <select id="ldt-selector">?

   Si NO existe:
   → Reconstruir archivo index.html
   → Asegurar que contenga el selector


PASO 5: Verificar logs del servidor
────────────────────────────────────

   En ventana de TEST_APP.bat, busca:

   Al iniciar:
   ✓ "📚 Cargando biblioteca de luminarias..."
   ✓ "✓ X luminarias cargadas"

   Al acceder a /api/luminarias:
   ✓ "DEBUG: Devolviendo X luminarias"

   Si ves ERROR:
   → Copiar mensaje exacto
   → Revisar ldt_reader.py

SOLUCIONES RÁPIDAS
═════════════════════════════════════════════════════════════════════════════

❌ "ZIP no encontrado":
   ✓ Verifica: assets/LDTs_luminarias.zip existe
   ✓ Intenta: descomprimir el ZIP manualmente
   ✓ Asegúrate: que contiene archivos .ldt

❌ "0 luminarias cargadas":
   ✓ ZIP vacío o sin .ldt
   ✓ Revisa ZIP en otro programa
   ✓ Comprueba extensión es .ldt (no .txt)

❌ "Error al parsear LDT":
   ✓ Formato de archivo .ldt incorrecto
   ✓ Encoding: probar con notepad++
   ✓ Primeras líneas tienen datos?

❌ Dropdown no aparece en HTML:
   ✓ Ctrl+Shift+K → búsqueda: "ldt-selector"
   ✓ Si no está: reconstruir index.html
   ✓ Copiar selector desde NUEVA_FUNCIONALIDAD_LDTS.txt

❌ Dropdown aparece pero vacío:
   ✓ /api/luminarias devuelve 0?
   ✓ F12 → Network → api/luminarias → Response
   ✓ ¿{"success": false}?

❌ "ReferenceError: cargarLuminarias is not defined":
   ✓ Función no se definió en index.html
   ✓ Buscar: "function cargarLuminarias()"
   ✓ Si no existe: agregar antes de </script>
