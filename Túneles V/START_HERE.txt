├─ Comando: pip install -r requirements.txt
├─ Comando: python app.py
└─ Para: Usuarios avanzados

🏃 PRIMER USO - MODO MANUAL
═══════════════════════════════════════════════════════════════════════════

1. Ejecuta run.bat
2. Abre http://localhost:5000
3. Completa:
   • Nombre proyecto: "Prueba 1"
   • Cliente: "Mi Cliente"
   • Localización: "Mi Ciudad"
   • Proyectista: "Tu Nombre"
   • Fecha: "16/05/2026"
   • Selecciona "Modo Manual"
4. Completa Geometría, Luminarias, Energía
5. Presiona "Enviar"
6. ¡Descarga el Excel generado!


🏃 SEGUNDO USO - MODO EXCEL
═══════════════════════════════════════════════════════════════════════════

1. En la app: "Descargar Plantilla"
2. Abre el Excel descargado
3. Completa con 1-5 estudios (uno por fila)
4. En la app: Selecciona "Modo Excel"
5. Importa el Excel
6. ¡Descarga los resultados!


❓ PREGUNTAS FRECUENTES
═══════════════════════════════════════════════════════════════════════════

P: ¿No veo la app después de ejecutar?
R: Abre el navegador en http://localhost:5000

P: ¿Cómo detengo la app?
R: Presiona Ctrl+C en la ventana de terminal

P: ¿Puedo cambiar el puerto?
R: Edita app.py línea 166: cambiar port=5000 a otro número

P: ¿Qué hago si sale error?
R: Lee RUN_INSTRUCTIONS.md sección "Solución de Problemas"

P: ¿Cómo agrego más estudios?
R: Usa Modo Excel para importar múltiples estudios de una vez
